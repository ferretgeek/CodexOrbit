# Codex Orbit v3.2.0

## 简体中文

这是 Codex Orbit 首次公开、可复现的 GitHub Release。它提供本地优先、零项目
遥测的 Windows Codex 额度悬浮窗，并同时发布独立 EXE、双语文档 ZIP 和
SHA-256 校验文件。

### 重点

- 兼容当前 Codex App Server 的稀疏额度通知，实时变化不再因缺少窗口字段而
  丢失。
- 修复迷你窗内容扩展后越出屏幕，并改善多显示器停靠位置恢复。
- 实时服务失败后采用 15 秒退避，同时保留 30 秒最近快照缓冲。
- App Server 输入固定为无 BOM UTF-8，避免终端代码页破坏 JSONL 协议。
- 额度通知使用独立调度并直接更新快照，避免繁忙线程池造成延迟。
- 增强设置校验、退出竞态保护和后台刷新稳定性。
- 确定性测试覆盖协议合并、本地日志解析、额度阈值、套餐、重置通知和窗口定位。
- 适配官方 GitHub Actions v7，并增强托管 CI 冷启动稳定性。
- 补齐中英双语使用、隐私、安全、贡献、支持、架构、发布及社区协作资料。

### 下载

- `CodexOrbit-3.2.0-windows-x64.exe`：独立程序。
- `CodexOrbit-3.2.0-windows-x64.zip`：程序、双语文档及包内 EXE 校验值。
- `SHA256SUMS.txt`：两个下载文件的 SHA-256。

需要 Windows 10/11 x64、.NET Framework 4.8，以及已使用 ChatGPT 账户登录的
Codex App、CLI、受支持 IDE 扩展或 WSL Codex CLI。

> 本项目是非官方社区项目，与 OpenAI 没有隶属、授权或背书关系。发布二进制未
> 使用商业代码签名证书，首次运行时 Windows SmartScreen 可能显示未知发布者。

## English

This is the first public, reproducible GitHub release of Codex Orbit: a
local-first Windows widget for Codex quota with no project telemetry. The
release includes a standalone executable, a bilingual documentation archive,
and SHA-256 checksums.

### Highlights

- Supports sparse quota notifications in the current Codex App Server schema,
  so live changes are not dropped when window metadata is omitted.
- Keeps expanded mini windows on-screen and improves dock restoration across
  monitors.
- Adds a 15-second retry backoff after live-service failures while retaining a
  30-second last-snapshot grace period.
- Pins App Server input to BOM-less UTF-8 to keep console code pages from
  corrupting JSONL transport.
- Dispatches quota notifications independently and publishes snapshots
  directly, avoiding delays from a busy thread pool.
- Hardens settings validation, shutdown races, and background refresh.
- Expands deterministic coverage for protocol merging, local-log parsing,
  thresholds, plans, reset notifications, and window placement.
- Updates to official GitHub Actions v7 and hardens hosted-runner cold starts.
- Adds complete Chinese and English user, privacy, security, contribution,
  support, architecture, publishing, and community documentation.

### Downloads

- `CodexOrbit-3.2.0-windows-x64.exe`: standalone application.
- `CodexOrbit-3.2.0-windows-x64.zip`: application, bilingual documentation,
  and an internal executable checksum.
- `SHA256SUMS.txt`: SHA-256 for both downloadable assets.

Requires Windows 10/11 x64, .NET Framework 4.8, and a Codex App, CLI, supported
IDE extension, or WSL Codex CLI signed in with a ChatGPT account.
