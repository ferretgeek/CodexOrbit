# Codex Orbit v3.2.1

## 简体中文

v3.2.1 是一次面向隐私、构建稳定性和发布供应链的维护版本。额度显示与交互保持
兼容，同时减少内存中保留的账户字段、约束本地诊断，并消除会导致重复失败邮件的
CI 重复触发。

### 重点

- `account/read` 返回后立即丢弃邮箱及无关账户字段，只在内存缓存认证要求、
  账户类型和套餐类型。
- `error.log` 增加用户路径与常见密钥格式脱敏、单条长度限制和约 512 KiB
  文件轮换；日志不会自动上传。
- 补充当前协议中的 Business、Enterprise 套餐映射、账户最小化和诊断脱敏测试。
- Build 只针对 `main` 的 push 和 PR 运行，不再为同一 PR 分支重复构建。
- GitHub Actions 固定到完整提交 SHA，并增加 C# CodeQL
  `security-extended` 扫描。
- Release 资产新增 GitHub 构建来源证明；ZIP 使用稳定排序和提交时间戳打包。
- 补齐全部中英双语隐私、安全、支持、架构、贡献和发布说明。

### 下载与验证

- `CodexOrbit-3.2.1-windows-x64.exe`：独立程序。
- `CodexOrbit-3.2.1-windows-x64.zip`：程序、双语文档与包内 EXE 校验值。
- `SHA256SUMS.txt`：两个下载文件的 SHA-256。

核对 SHA-256 后，还可以使用 GitHub CLI 验证来源：

```powershell
gh attestation verify .\CodexOrbit-3.2.1-windows-x64.exe `
  --repo ferretgeek/CodexOrbit
```

需要 Windows 10/11 x64、.NET Framework 4.8，以及已使用 ChatGPT 账户登录的
Codex App、CLI、受支持 IDE 扩展或 WSL Codex CLI。

> 不等同于商业 Authenticode 代码签名；Windows SmartScreen 仍可能显示未知
> 发布者。

## English

v3.2.1 is a maintenance release focused on privacy, build stability, and the
release supply chain. Quota behavior and controls remain compatible while the
application retains fewer account fields, bounds local diagnostics, and avoids
duplicate CI triggers that could generate redundant failure email.

### Highlights

- Discards email and unrelated account fields immediately after
  `account/read`, retaining only the authentication requirement, account type,
  and plan type in memory.
- Redacts user paths and common secret formats from `error.log`, limits each
  entry, and rotates the file at approximately 512 KiB. Diagnostics are never
  uploaded automatically.
- Covers current Business and Enterprise plan identifiers, account
  minimization, and diagnostic redaction with deterministic tests.
- Runs Build only for pushes and pull requests targeting `main`, avoiding
  duplicate runs for the same pull-request branch.
- Pins every GitHub Action to a complete commit SHA and adds C# CodeQL
  `security-extended` analysis.
- Adds GitHub build-provenance attestations for Release assets and packages ZIP
  entries with stable ordering and commit-derived timestamps.
- Completes the bilingual privacy, security, support, architecture,
  contribution, and publishing documentation.

### Downloads and verification

- `CodexOrbit-3.2.1-windows-x64.exe`: standalone application.
- `CodexOrbit-3.2.1-windows-x64.zip`: application, bilingual documentation,
  and an internal executable checksum.
- `SHA256SUMS.txt`: SHA-256 for both downloadable assets.

After checking SHA-256, GitHub CLI can also verify provenance:

```powershell
gh attestation verify .\CodexOrbit-3.2.1-windows-x64.exe `
  --repo ferretgeek/CodexOrbit
```

Requires Windows 10/11 x64, .NET Framework 4.8, and a Codex App, CLI, supported
IDE extension, or WSL Codex CLI signed in with a ChatGPT account.
