# Support

[简体中文](SUPPORT.md)

## Before opening an issue

1. Install the latest release.
2. Confirm Codex App or CLI can open and is signed in with a ChatGPT account.
3. Choose **Refresh now** from the tray menu.
4. Review the troubleshooting section in [README.en.md](README.en.md).
5. Run `.\scripts\test.ps1` only if you are building from source.

## Where to ask

- Reproducible bug: use the bug-report issue form.
- Product idea: use the feature-request form.
- Possible vulnerability: follow [SECURITY.en.md](SECURITY.en.md) and do not
  open a public report with sensitive details.
- Codex account, billing, or plan issue: contact official OpenAI support; this
  community project cannot inspect or change accounts.

Reports may be written in English or Simplified Chinese.

## Safe diagnostics

Include the Codex Orbit version, Windows version, runtime type, visible status
message, and minimal steps. Do not include tokens, API keys, cookies, complete
session logs, real account screenshots, or unredacted user paths.
